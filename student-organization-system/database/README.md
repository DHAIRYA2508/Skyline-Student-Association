# Database Management

This directory contains database schemas, Alembic migrations, and seed scripts for MySQL 8+.

## Directory Structure

- `schema/`: Initial DDL scripts and baseline SQL schema files.
- `migrations/`: Migration scripts (Alembic).
- `seeds/`: Seed data for development and testing.

## Tech Stack

- Database: MySQL 8+
- Storage Engine: InnoDB
- ORM: SQLAlchemy 2.0
