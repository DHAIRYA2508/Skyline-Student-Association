# Skyline Student Association – Frontend

Standalone React + TypeScript app (beige theme). Data is stored in the browser (localStorage), so no backend is needed to demo it.

    npm install
    npm run dev

Demo logins: admin@skyline.edu / admin123  ·  riya@skyline.edu / member123
Every Pay button opens a checkout gateway (UPI / Card / Net Banking, test mode).
To reset demo data: clear site data for localhost.
